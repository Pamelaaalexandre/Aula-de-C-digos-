# 💻 Tecnologias e Conceitos Praticados

Este repositório reúne implementações práticas focadas em lógica de programação estruturada e análise de dados inicial utilizando Python.

### 🛠️ Estruturas de Controle e Fluxo
- **Laços de Repetição (`while`):** Desenvolvimento de loops condicionais e estruturas de repetição infinita (`while True`) com critérios de parada (`break`).
- **Controle de Acesso:** Algoritmo para validação de senhas com limite máximo de tentativas seguras.
- **Interação com Usuário:** Captação de entradas dinâmicas em tempo real para manipulação de listas.

### 📦 Estruturas de Dados
- **Listas Mutáveis:** Criação, leitura e inserção de novos elementos de forma dinâmica (`append`).
- **Dicionários (Chave-Valor):** Estruturação e manipulação de objetos complexos (como contas e saldos bancários), além de consultas específicas utilizando métodos como `.keys()` e `.values()`.

### 📊 Análise de Dados com Pandas
- **Importação de Bibliotecas:** Utilização da biblioteca `pandas` (apelidada como `pd`) para manipulação de dados estruturados.
- **Manipulação de Arquivos Externos:** Leitura de arquivos estruturados no formato `.csv` (`read_csv`).
- **Exploração e Estatística Descritiva:** Execução de diagnósticos estruturais de tabelas (`info()`) e geração automática de métricas estatísticas essenciais como média, mediana, desvio padrão, valores mínimos e máximos (`describe()`).
